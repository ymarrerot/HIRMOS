# Design-Agent Lineage

`system-design-agent` is the first serious extension family migrated from the original framework design subsystem.

It preserves:
- cycle-first design
- guide/prompt discipline translated into entrypoints + Specs
- Source-of-Truth artifact generation
- staged-delivery awareness
- parity-reviewed rebuild discipline

This lineage is preserved in the extension's public specs, entrypoints, templates, and user-facing docs.
