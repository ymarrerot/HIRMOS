# Failed Template — implementation

Use this template for `implementation-agent:implementation` when the public Implementation step cannot produce a governable completed or paused result.
All required sections below must appear in the final surfaced failed output.

## Command

`hirmos implementation`

## Selected phase

State the selected/current phase exactly, or state that phase selection could not be established.

## Run state

`failed`

## Failure reason

Explain the command-critical failure.

## What was attempted

Summarize what was attempted before failure.

## Major artifacts created or refined

List any artifacts created or materially refined before failure, or state that none were produced.

## Validation or grounding result

Report the validation or grounding result that supports the failed state.

## Why pause was not sufficient

Explain why a governable paused state was not available.

## Next action

State the recommended Orchestrator action.

## Updated working copy zip

Include the surfaced download link for the updated full working copy.
