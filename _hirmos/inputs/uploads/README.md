# Uploaded Inputs

Place user-provided uploaded files here when they are useful to preserve inside the project-local HIRMOS workspace.

Examples:

- `requirements.txt`
- exported chat notes
- screenshots or PDFs referenced by the user
- product notes or stakeholder material

Uploaded inputs are raw source material. They are not governed requirements until HIRMOS reconciles them into the active session artifacts.


These inputs are not authority until HIRMOS reconciles them into governed session or accepted-state artifacts.
