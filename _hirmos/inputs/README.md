# Source Inputs

This folder is the default place for raw source material that a user or project owner gives to HIRMOS.

Inputs are **evidence and focus signals**. They are not requirements authority, design authority, implementation authorization, or accepted current state by themselves.

Use this surface for material such as:

- uploaded requirements notes;
- exported conversations;
- screenshots or UI references;
- prototype or proof-of-concept artifacts;
- domain notes and reference documents.

HIRMOS may read these files during intake and design, but governed artifacts such as `REQUIREMENTS_BASELINE.md`, `SESSION_CONTRACT.md`, and `unresolved-items.md` decide what becomes authorized work.

## Folders

```text
_hirmos/inputs/
  uploads/ user-provided files and requirement notes
  prototypes/ prototype, POC, generated-app, and UI reference material
  references/ domain references and supporting background material
```
