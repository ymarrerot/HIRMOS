# Folder Rules — Reference

This folder is for cross-cutting reference material that supports multiple reader paths.

Content here should:

- define terms, artifact models, folder surfaces, and runtime surfaces;
- be easy to link from Use HIRMOS, Methodology, and Extend & Contribute docs;
- avoid becoming a miscellaneous drawer.

Content here should not:

- introduce new doctrine;
- duplicate methodology explanations;
- replace Track 1 onboarding or Track 2 authoring guidance;
- become the first required reading path for new users.
