# Framework Guidance

Use this lane when you want the framework mental model without dropping into the authority lane too early. It is the best place to understand how HIRMOS fits governed AI-assisted work into a familiar software delivery flow. This is a good next lane after getting started, but it is still not a command to read everything here at once.

If you just finished getting started, use this lane in a simple order:

1. [Conceptual diagram](./conceptual-diagram.md) — the simplest picture of what HIRMOS is
2. [Workflow diagram](./workflow-diagram.md) — how work moves through the framework across familiar SDLC stages
3. [Framework operating model](./framework-operating-model.md) — how the main layers fit together in practice

You do not need the rest of this lane immediately. Come back to the deeper pages only when a real question appears.
