# Folder Rules

## Purpose

Define what `/_hirmos/docs/core/` is for, what it owns, what it must not own, and which nearby folders it is commonly confused with.

## This folder owns

- human-friendly explanation of the Core
- Core mental models
- practical guidance for understanding Core behavior
- standalone practical guidance with references into `/_hirmos/core/authority/core/` only when deeper authoritative detail is needed

## This folder must not own

- canonical Core doctrine
- broader framework doctrine
- extension authoring standards

## Common boundary confusions

Most common confusions:
- `/_hirmos/core/authority/core/`
- `/_hirmos/docs/framework/`

## If you are unsure

Ask:
- Is this helping a human **understand the Core** rather than defining the Core’s final rules?

If yes, it likely belongs here.
