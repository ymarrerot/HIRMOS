# Use HIRMOS

Use this path if you want to run HIRMOS on a software project.

After installation, use `hirmos init` when the CLI is available to generate agent-native bootstrap files:

```bash
hirmos init
```

If you are not using the CLI yet, initialize the AI session directly with:

```text
Read and follow the instructions on _hirmos/HIRMOS_CORE.md
```

Then start here:

1. [Install and Initialize HIRMOS](getting-started/install-and-initialize.md)
2. [Use HIRMOS in 3 Steps](getting-started/use-hirmos-in-3-steps.md)
3. [Quickstart](getting-started/quickstart.md)
4. [First Real Run](getting-started/first-real-run.md)
5. [Decision Checkpoints](orchestrator/decision-checkpoints.md)

After that, use the optional guides:

- [Understanding HIRMOS](understanding/README.md)
- [Orchestrator guidance](orchestrator/operator-playbook.md)
- [Examples](examples/README.md)

You do not need to read Core, extension-authoring, hook, or manifest documentation before running HIRMOS.
