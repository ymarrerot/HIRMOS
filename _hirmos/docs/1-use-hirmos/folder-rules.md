# Folder Rules — Use HIRMOS

This folder is for regular users who want to run HIRMOS on software projects.

Content here should:

- explain the practical user flow;
- favor short reading paths;
- use real HIRMOS artifact names where clear;
- avoid requiring framework internals before the user can start;
- link to methodology or reference docs only when they help the user understand what they are seeing.

Content here should not:

- define Core authority;
- teach extension authoring as the default path;
- expose hook, manifest, or runtime-control details before they are needed;
- duplicate docs from `3-extend-contribute/`.
