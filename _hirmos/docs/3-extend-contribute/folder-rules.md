# Folder Rules — Extend & Contribute

This folder is for power users, contributors, private extension authors, and community extension authors.

Content here should:

- explain how HIRMOS works internally;
- teach safe extension authoring and contribution practices;
- preserve the separation between Core, framework docs, and extension docs;
- link to methodology when explaining why a rule exists;
- avoid duplicating methodology content that belongs under `../2-methodology/`.

Content here should not:

- become the default path for regular users;
- hide framework mechanics that extension authors need;
- duplicate Core authority as prose;
- weaken runtime controls, validation, hook governance, or fail-closed behavior.
