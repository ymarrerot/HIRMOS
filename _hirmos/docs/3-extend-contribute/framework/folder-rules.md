# Folder Rules

## Purpose

Define what `/_hirmos/docs/3-extend-contribute/framework/` is for, what it owns, what it must not own, and which nearby folders it is commonly confused with.

## This folder owns

- user-facing framework guidance
- conceptual explanations
- diagrams and mental models
- practical orientation to the framework
- standalone practical guidance with references into deeper Specs only when readers want canonical detail

## This folder must not own

- final framework doctrine
- review-grounding source-of-truth material
- Core-local doctrine

## Common boundary confusions

Most common confusions:
- `/_hirmos/core/authority/framework/`
- `/_hirmos/docs/3-extend-contribute/core/`

## If you are unsure

Ask:
- Is this helping a human **understand or navigate the framework** rather than defining the final rule?

If yes, it likely belongs here.
