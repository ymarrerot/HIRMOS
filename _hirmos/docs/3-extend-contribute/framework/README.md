# Framework Guidance

Use this lane when you want the framework mental model without dropping into the authority lane too early. It is the best place to understand how HIRMOS fits governed AI-assisted work into a familiar software delivery flow.

HIRMOS is an open modular framework for Orchestrated Spec-Driven Development.

The regular-user workflow is:

```text
Requirements → System Design → Implementation
```

You do not need the rest of this lane immediately. Come back to the deeper pages only when a real question appears.
