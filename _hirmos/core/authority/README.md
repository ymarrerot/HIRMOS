# /_hirmos/core/authority/

This is the central home for HIRMOS authoritative doctrine.

Use this lane when you need canonical rules, contracts, role boundaries, or standards. It is not the first-stop onboarding path for a new user.

If you are new to HIRMOS, start with:
- [Docs hub](../../docs/README.md)
- [Getting started](../../docs/getting-started/README.md)

## Authority lanes

- `shared/` — cross-cutting authority-system rules used across the framework
- `core/` — authoritative Core-local behavior and interpretation
- `framework/` — framework-wide authoritative doctrine
- `extensions/` — framework-wide extension doctrine and authoring standards

## Usage rule

Use this lane for canonical truth.

Use `/_hirmos/docs/` for onboarding, practical guidance, and user-facing explanation.


The Core authority layer now uses `identity-display-execution-control.md` and `hook-execution-control.md` as the governing files for those execution controls.
